# 前后端分离计算器 - 前端

## 项目简介

本仓库是软件工程实践第一次作业的前端项目。前端负责界面、按键交互、表达式输入、API 请求、结果显示和历史记录显示；数学表达式的最终计算结果不在前端生成。

## 技术栈

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API

## 目录

```text
src/
├── index.html
├── style.css
├── config.js
└── app.js
```

## 配置后端地址

编辑 `src/config.js`：

```js
window.APP_CONFIG = {
    API_BASE_URL: "http://127.0.0.1:8000",
};
```

部署后将其改成公网后端 HTTPS 地址。

## 本地启动

在仓库根目录执行：

```bash
python -m http.server 5500 -d src
```

浏览器访问：`http://127.0.0.1:5500`

## 功能

- 四则运算按钮和文本输入
- 复合表达式、括号、小数、一元正负号
- Enter 计算、Esc 清空
- 后端在线状态提示
- SQLite 历史记录展示
- 删除指定历史记录
- 扩展：清空全部历史记录
- 扩展：明暗主题切换

## 前后端分离验证

停止后端服务后，前端仍能输入表达式和操作界面，但点击 `=` 无法产生新的有效计算结果，从而证明核心计算逻辑位于后端。
